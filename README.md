# 🧪 Superlists — Практика TDD на Python (по Гарри Персивалю, 3-е издание)

Учебный проект, созданный в процессе изучения методологии **TDD (Test-Driven Development)** по книге Гарри Персиваля **«Test-Driven Development with Python: Obey the Testing Goat!» (3rd Edition)**.

Основная концепция проекта — разработка веб-приложения "от теста к коду" (подчинение Тестирующему Козлу 🐐), соблюдая строгий баланс между функциональным и модульным тестированием.

## 🎯 Ключевые концепции и подходы
В ходе проекта реализованы следующие практики:
* **Двойной цикл TDD:** Написание макро-тестов (функциональных) для пользовательских историй и микро-тестов (модульных) для внутренней логики приложения.
* **Red-Green-Refactor:** Строгое следование циклу разработки — сначала пишется провальный тест, затем минимальный рабочий код, после чего проводится рефакторинг.
* **Тестирование базы данных:** Изолированные тесты моделей Django, проверка миграций и валидации полей.
* **CI/CD мышление:** Настройка структуры проекта для легкой автоматизации прогона тестов.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.x
* **Веб-фреймворк:** Django
* **Тестирование (Браузерное/E2E):** Selenium WebDriver
* **Тестирование (Модульное):** Python unittest / pytest

## 📁 Структура тестов в проекте
* `functional_tests/` — функциональные (интеграционные) тесты, симулирующие реальное поведение пользователя в браузере с помощью Selenium.
* `[app_name]/tests/` — модульные тесты для проверки Django views, моделей и форм.

## 🚀 Инструкция по запуску тестов локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd имя-репозитория
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запуск модульных тестов Django:**
   ```bash
   python manage.py test
   ```

5. **Запуск функциональных тестов (требуется установленный браузер и драйвер, например, Geckodriver/Firefox):**
   ```bash
   python functional_tests/tests.py
   ```
